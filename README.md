# JW Library Backup Merger

Merge multiple JW Library (`.jwlibrary`) backups together completely in your browser.

- 🔒 **100% In-Browser & Private:** No files are uploaded to any server. Powered by WebAssembly SQLite (`sql.js`).
- ⚡ **Multi-Block Highlight Healing:** Completely eliminates the JWLMerge highlight truncation bug.
- 📱 **Multi-Device Support:** Combine notes and highlights from iPad, iPhone, Android, and PC.
- 🚀 **Cloudflare Pages Ready:** High-speed static deployment.

## Quick Start

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## Build for Cloudflare Pages

```bash
npm run build
```

Upload the `dist/` directory to Cloudflare Pages or deploy via GitHub.
